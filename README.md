My entry deletes **almost** — the word that props up every near-miss, every excuse, and every almost-famous story. Without it, nobody almost won the lottery, nobody almost made it, and every humblebrag collapses into either did or didn't. A world with no almosts is a world with no excuses, and that is instantly, obviously funny.
